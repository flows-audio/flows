directories retain Apache-2.0. Dependencies keep their original licenses;
the project license does not replace them.

## JUCE

The desktop app, audio devices and plugin wrappers use **JUCE 8.0.7**:

- Source: https://github.com/juce-framework/JUCE/tree/8.0.7
- Pinned commit: `10a589619b452c261b2940767eb253171eb5a823`
- License: https://github.com/juce-framework/JUCE/blob/8.0.7/LICENSE.md

This open-source application uses the **AGPLv3** option of JUCE's dual license.
No commercial JUCE license is included or implied. Generated AU/VST3 wrapper
adapters are modified JUCE code and remain under the applicable JUCE license.
The adapter script checks the original source hashes before making copies.

JUCE embeds dependencies including AudioUnitSDK (Apache-2.0), FLAC and Ogg
Vorbis (BSD-style licenses), PNG/zlib, JPEG, HarfBuzz, SheenBidi, CHOC/QuickJS
and VST3 SDK. The pinned VST3 SDK offers a GPLv3 option, which is the option
used for the open-source VST3 target. Upstream notices, rather than a newer
SDK's license, apply to this pinned version. License texts are preserved in
`licenses/third-party/juce/` and included in release bundles.

## Frontend

React, React DOM, CodeMirror, Lezer, react-markdown, remark-gfm and their
runtime dependency tree use their respective upstream licenses, predominantly
MIT. `ui/package-lock.json` pins versions and integrity hashes. Full package
license texts are collected in `licenses/third-party/ui.txt`; the collector
fails when a runtime package lacks its license file. Build tools such as Vite
and TypeScript are not distributed as runtime executables.

To regenerate and verify notices after dependency changes:

```sh
npm ci --prefix ui
python3 tools/collect_licenses.py --juce-dir ../JUCE
```

## Browser build

The browser build is compiled with **Emscripten 6.0.13**. Its output links
libc++, libc++abi and libunwind (Apache-2.0 WITH LLVM-exception), compiler-rt
(the same license), musl libc (MIT) and Emscripten's JavaScript runtime
(MIT/University of Illinois NCSA). The default allocator, dlmalloc, is public
domain. Their notices are in `licenses/third-party/emscripten/` and ship in the
web release with the UI notices; JUCE is not part of the browser build.

```sh
python3 tools/collect_licenses.py --emscripten-dir <emscripten root>
```

Playwright, esbuild and the Node type definitions are development tools only.

## Flows assets and algorithms

The two audio fixtures are generated by
`test/fixtures/samples/generate.py`, with no external recordings. They and the
Flows icon/example instruments are original project assets distributed under
the project license. Personal imported samples are not included.

The engine cites the mathematical methods used for anti-aliased waveshaping
and filtering beside their implementations. Those research references are
attribution, not a claim that third-party source code has been relicensed.
Keep existing source notices when modifying or redistributing code.
