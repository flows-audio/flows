Flows Embed

A playable Flows instrument for any web page. It needs no special server headers, and every colour, corner and font can come from your site.

Add it to a page

<script type="module" src="https://flows-audio.github.io/flows/embed/flows-embed.js"></script>
<flows-instrument preset="soft-keys"></flows-instrument>

Examples

  • Minimal blog: no styling at all; the instrument takes the article's font and colours.
  • Liquid glass: a custom layout restyled with parts to match a glass personal site.
  • Dark portfolio: the engine alone, driven by the page's own pads, sliders and visuals.

Documentation

The integration guide covers the three layers, every --flows-* variable and part, framework snippets and browser audio rules. It doubles as a skill for coding agents.
